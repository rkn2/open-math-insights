Do students get better with practice? Learning curves in the ASSISTments data¶

A classic educational-data-mining analysis: for each skill, the opportunity column counts how many times a student has practiced that specific skill so far. Plotting average correctness against opportunity number produces a learning curve — if practice works, correctness should climb as opportunity number increases. Real data — see data/public/assistments-2009-2010-skill-builder/SOURCE.md.

# Overall learning curve: correctness by opportunity number, capped at 20
# (opportunity counts get sparse — and noisy — past that for most skills).
curve = (
    df[df["opportunity"] <= 20]
    .groupby("opportunity")["correct"]
    .agg(["mean", "count"])
)

fig, ax = plt.subplots(figsize=(8, 5))
ax.plot(curve.index, curve["mean"], marker="o", color="#4f46e5")
ax.set_xlabel("Opportunity number (nth time practicing this skill)")
ax.set_ylabel("Correct rate")
ax.set_title("Learning curve: correctness vs. practice opportunity")
ax.grid(alpha=0.3)
plt.show()

Do students also get faster, not just more accurate?¶

In [3]:
speed_curve = (
    df[(df["opportunity"] <= 20) & (df["ms_first_response"] > 0)]
    .groupby("opportunity")["ms_first_response"]
    .median()
    / 1000
)

fig, ax = plt.subplots(figsize=(8, 5))
ax.plot(speed_curve.index, speed_curve.values, marker="o", color="#f97316")
ax.set_xlabel("Opportunity number")
ax.set_ylabel("Median time to first response (seconds)")
ax.set_title("Response time vs. practice opportunity")
ax.grid(alpha=0.3)
plt.show()

The same curve, by individual skill¶

Some skills show a much steeper learning curve than others — try swapping in a different skill name from 02_assistments_knowledge_tracing.ipynb's "hardest skills" chart.

SKILL = "Box and Whisker"

skill_curve = (
    df[(df["skill_name"] == SKILL) & (df["opportunity"] <= 15)]
    .groupby("opportunity")["correct"]
    .agg(["mean", "count"])
)

fig, ax = plt.subplots(figsize=(8, 5))
ax.plot(skill_curve.index, skill_curve["mean"], marker="o", color="#0d9488")
ax.set_xlabel("Opportunity number")
ax.set_ylabel("Correct rate")
ax.set_title(f"Learning curve for skill: {SKILL}")
ax.grid(alpha=0.3)
plt.show()
