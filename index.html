Metadata Quality Standards

What makes a math education dataset AI-ready? These standards define documentation, annotation reliability, and schema alignment criteria across the CAMEL network.

AI-Ready Dataset Checklist

  • Dataset description and research context documented
  • Variable definitions with units and valid ranges
  • Annotation codebook with decision rules
  • Inter-rater reliability reported (κ ≥ 0.70)
  • Schema mapped to xAPI/Caliper vocabulary
  • De-identification procedures documented
  • License and reuse terms specified
  • Sample data or data dictionary publicly available

Quality Tier Definitions

Gold

Fully documented. Inter-rater κ ≥ 0.70 established. Schema aligned to xAPI/Caliper. PII procedures documented. Ready for cross-project analysis.

Silver

Documentation complete. Reliability established but schema not yet aligned across projects. Usable within its own project context.

Bronze

Partially documented. Reliability pending or below threshold. Indexed for discoverability; quality improvements in progress.

Schema Alignment

Cross-project analysis requires common vocabulary. These guidelines map CAMEL data to xAPI and Caliper standards so "student struggle" means the same thing across all five projects.

verb: "attempted" → xapi:attempted
object: "fraction-problem" → cmi:interaction
result: "struggle-flag" → ext:struggle-indicator

Annotation Reliability

Every human-coded annotation in the catalog reports Cohen's kappa against a second coder. The threshold for Gold-tier is κ ≥ 0.70. AI-assisted annotations must demonstrate equivalent reliability against human coders on pilot data before bulk use.

≥ 0.70
Gold threshold
0.50–0.69
Silver range
